📊 My Excel Dashboard Project | Turning Sales Data into Business Insights

I'm excited to share a project I recently created using Microsoft Excel and PivotTables! 🚀

As part of my journey toward becoming a Data Analyst, I wanted to apply my learning practically by building an interactive sales dashboard.

📌 What does this dashboard include?

✅ Executive Summary with key business KPIs
✅ Total Revenue, Gross Profit, Profit Margin & COGS
✅ Monthly Revenue and Profit Trends
✅ Top Countries by Revenue
✅ Revenue Share by Sales Channel
✅ Regional Sales Comparison
✅ Interactive Product and Country Slicers

🎯 What I learned from this project:

• Using PivotTables to summarize and analyse sales data
• Creating charts to communicate business performance
• Tracking KPIs and identifying trends
• Building an interactive dashboard for easier data exploration

💡 My learning journey: I built this dashboard myself with the help of ChatGPT, YouTube tutorials, and my own practice. Every step helped me understand Excel better and improve my analytical thinking.

I believe the best way to learn data analytics is to keep practising, build real projects, and learn from every mistake.
